# GitHub Pages – ohne Domainkauf
Noch nicht öffentlich bereitgestellt. Nur der Inhalt dieses HOSTING-Ordners gehört ins öffentliche Repository. Keine Masterdateien, QA-Berichte oder KDP-Unterlagen hochladen.

1. Bei GitHub im eigenen Browser anmelden oder kostenlos registrieren. Passwort und 2FA ausschließlich dort eingeben.
2. Öffentliches Repository namens hausjahr anlegen. Ein Organisations-/Kontoname Werkpfad Edition ist nur zu verwenden, wenn tatsächlich verfügbar und eingerichtet. Kein Benutzername wird vorausgesetzt.
3. Add file → Upload files: index.html, style.css, impressum.html, datenschutz.html, .nojekyll und die sechs Download-Dateien aus diesem Ordner hochladen. Im Hauptverzeichnis speichern, nicht in einem Unterordner HOSTING. README-HOSTING.md ist nur diese Übergabehilfe und braucht nicht öffentlich zu werden.
4. Settings → Pages → Deploy from a branch → main → /(root) → Save. Kostenlose Pages sind für öffentliche Repositorys verfügbar. Keine Domain eintragen und keine kostenpflichtigen Zusatzfunktionen buchen.
5. Erst die von GitHub angezeigte tatsächliche Seitenadresse öffnen. Alle sechs Dateien herunterladen und HTTPS sowie Smartphoneansicht prüfen. Dies ist die endgültige Leseradresse; keinen Wunsch-Accountnamen in die Druckdatei übernehmen.
6. Die erfolgreich getestete URL in EDITABLE/publikation.json unter download_url speichern, download_verified auf true setzen und den Produktionslauf erneut starten. Dann werden URL und QR-Code erzeugt. Probeausdruck des QR-Codes mit dem Telefon öffnen.
7. Bei Updates Dateinamen und Repositorypfad erhalten. Version und Korrekturhinweise in index.html anpassen; bestehende Leseradresse behalten. Ältere Fassungen bei Bedarf in einem Versionsunterordner archivieren.

GitHub Pages ist hier als frei zugängliche Material-/Projektdokumentation ohne Shop, Kaufverweise, Werbung, Newsletter oder kommerziellen Transaktionsprozess vorbereitet. GitHubs Bedingungen untersagen insbesondere den Betrieb eines Online-Geschäfts über Pages; eine generelle Freigabe für jedes Verlagsangebot wird nicht behauptet. Die Seite nicht um Verkaufsfunktionen erweitern.
